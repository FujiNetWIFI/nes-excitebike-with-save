Excitebike track repository

Tracks saved from Excitebike's design mode on an NES with a FujiNet cartridge. In the game, SAVE asks for a track name and a two-digit slot (the player name comes from the FujiNet's shared app key) and LOAD lists the saved slots; every save is kept as a new version, so an overwritten track can still be fetched.

API

  • GET /api/track/NN the latest 320 bytes of slot NN (application/octet-stream), 404 when empty
  • POST /api/track/NN?name=MY+TRACK&user=THOM store exactly 320 bytes (64-byte header + 256-byte track) as a new version; answers OK
  • GET /api/tracks?bin=1&page=P a 204-byte page of ten slot records for the game (&slot=NN for one slot)
  • GET /api/track/NN/versions JSON list of versions; GET /api/track/NN/v/V one version's bytes
  • GET /api/tracks JSON summary of every slot in use
